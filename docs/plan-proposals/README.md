# Propostas de Plano

Este diretório reúne documentos que registram a intenção inicial de
implementar um projeto ou funcionalidade. Eles servem para discutir objetivo,
escopo e resultado esperado antes do início do trabalho.

Uma proposta aprovada deve ser convertida em um ExecPlan em
`docs/exec-plans/active/`, seguindo `PLANS.md`. Propostas não são ExecPlans e
não precisam seguir sua estrutura de documento vivo.
