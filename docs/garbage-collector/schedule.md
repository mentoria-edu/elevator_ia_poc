# Agenda

A execução inicial é manual. A equipe mantenedora deve executar:

    uv run python -m tools.garbage_collector check

antes de uma revisão periódica de manutenção ou quando houver suspeita de
artefatos obsoletos. Automação agendada não faz parte da primeira versão.
Inventário e relatório devem ser revisados por uma pessoa; a ferramenta não
autoriza exclusões automáticas.
