# Relatórios

Relatórios gerados pelo Garbage Collector são armazenados neste diretório.
Cada arquivo diário registra a configuração, as estatísticas, os candidatos e
as evidências da execução. Gere ou atualize o relatório com:

    uv run python -m tools.garbage_collector report

Os próximos passos sempre exigem revisão humana e não autorizam exclusão
automática.
